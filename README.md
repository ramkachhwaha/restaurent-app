## 📌 Project Overview
Excited to share this Full-Stack project! This application simulates a real-world restaurant platform where users can explore menus and submit reservations seamlessly. It is designed to be fully responsive and ensures smooth communication between the frontend and backend.

---

## 🔗 Live Application
🚀 **View Live Demo:** [https://restaurent-app-indol.vercel.app/](https://restaurent-app-indol.vercel.app/)

---

## 🔥 Key Functionalities

✅ **Browse Menu:** Users can explore various food categories (Breakfast, Lunch, Dinner). 
✅ **Online Reservation:** Seamless table booking form with validation. 
✅ **RESTful API Integration:** Robust backend communication for data handling. 
✅ **Fully Responsive Design:** Optimized for **Mobile, Tablet, and Desktop** views. 
✅ **Frontend-Backend Communication:** Real-time data processing using Axios/Fetch. 
✅ **Clean & Modern UI:** A visually appealing interface focused on user experience.

## 🚀 Getting Started (Installation)

Follow these steps to run the project locally on your machine.

### 1. Clone the Repository
```bash
git clone https://github.com/bhuv-sai/restaurent-app.git
cd restaurent-app
```

### 2. Backend Setup
Navigate to the backend folder and install dependencies:
```bash
cd Backend
npm install
```

**Configuration:**
Create a `config.env` file in the `Backend/config` folder with your credentials:
```env
PORT=4000
FRONTEND_URL=http://localhost:5173
MONGO_URI=your_mongodb_connection_string
```

Start the Server:
```bash
npm start
```

### 3. Frontend Setup
Open a new terminal, navigate to the frontend folder:
```bash
cd Frontend
npm install
```

Start the React App:
```bash
npm run dev
```
